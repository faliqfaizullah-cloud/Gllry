# Gllry
Android (Kotlin + Jetpack Compose), minSdk 30.
Build: open this folder in Android Studio, let Gradle sync, then Build > Build APK(s).
CLI: `gradle assembleDebug` -> app/build/outputs/apk/debug/app-debug.apk
Widget: long-press home screen > Widgets > Gllry (2x2).
Fonts: add Instrument Serif + Inter TTFs to app/src/main/res/font and edit Display/UiSans in Components.kt.
